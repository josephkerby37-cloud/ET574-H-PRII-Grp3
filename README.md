# ET574-H-PRII-Grp3
## ET-574 Project II – Math Function Library – Group 3

### Project Description
This project is a Python Math Function Library.
It contains mathematical functions created by group members.
Each function includes input validation and unit tests.

### Functions
- factorial(n): Calculates the factorial of a non-negative integer.
- volume_of_sphere(r): Calculates the volume of a sphere.
- sqrt(x): Calculates the square root of a non-negative number.
- area_of_circle(r): Calculates the area of a circle.

### Running the Tests
To run the unit tests, open the terminal and enter:

python3 -m unittest test_math.py -v

### Testing
The project uses Python's unittest framework to test
the mathematical functions and check for invalid inputs.

### Project Files
- my_math.py – Contains the mathematical functions.
- test_math.py – Contains the unit tests.
- issue_tracking.csv – Tracks project tasks.
