## Project Description

The purpose of this project is to create a shared mathematical function library using Python.

The library will contain original mathematical functions and approved core functions without relying on Python's built-in math module.

## Project Files

- my_math.py - Contains all mathematical functions.
- test_math.py - Contains unit tests for all functions.
- README.md - Contains project information and documentation.
- issue_tracking.csv - Tracks project tasks and issues.
